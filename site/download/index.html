First time opening it

This early version isn't signed by Apple yet, so macOS asks you to confirm the first time.

  1. Double-click the download in your Downloads folder to unpack it, then drag Loopwright into Applications.
  2. In Applications, right-click (or Control-click) Loopwright and choose Open, then Open again.
  3. If macOS only offers Move to Trash, open System Settings > Privacy & Security, scroll down and click Open Anyway.
  4. If it says the app "is damaged", open Terminal, paste this and press Return, then open the app again:
xattr -cr /Applications/Loopwright.app

If double-clicking doesn't unpack it, run this in Terminal instead: cd ~/Downloads && tar -xf Loopwright-mac-*.tar.xz
